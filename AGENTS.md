# Desenvolvimento

Em toda tarefa de desenvolvimento, leia e aplique estas skills locais:
- `.agents/skills/especialista-em-seo/SKILL.md`
- `.agents/skills/especialista-em-seguranca/SKILL.md`
- `.agents/skills/clean-code/SKILL.md`

Para commits, use `.agents/skills/git-commit-formatter/SKILL.md`.
Crie um commit semântico em pt-BR ao concluir cada etapa, com descrição concisa no imperativo e seguindo Conventional Commits.
Preserve as URLs do WordPress e valide a cobertura de `auxiliares/*-sitemap.xml`.
Não publique exportações, rascunhos, comentários ou dados pessoais do XML. Apenas `dist/` deve ser enviado à hospedagem.
